# Source-Lit Public Anchors

These source-lit guide anchors are expected to resolve from the v4 public
surface.

- `boundary_quality`: validates selected source bundle quality.
- `citable_source_ref`: checks whether a source carries a public citation key.
- `context_family`: normalizes source context labels.
- `fact_count`: counts source facts across selected papers.
- `fetch_papers`: retrieves source-literature candidate papers.
- `join_contexts`: renders normalized context labels.
- `paper_key`: derives a stable source paper key.
- `payload`: builds the source-literature publish payload.
- `query_variants`: expands source-literature topic queries.
- `relevant_papers`: filters candidate papers by topic relevance.
- `select_boundary_papers`: selects the publishable boundary bundle.
- `source_fact`: extracts the canonical source fact object.
- `source_identity_count`: counts distinct source identities.
- `source_identity_key`: derives a source identity key.
- `source_outlet_count`: counts source outlets.
- `source_outlet_diversity_below_min`: checks outlet diversity floors.
- `source_outlet_key`: derives a source outlet key.
- `source_outlet_metadata_count`: counts source outlet metadata rows.
- `substantive_fact_count`: counts substantive source facts.
- `title_key`: normalizes titles for source-lit matching.
- `topic_relevant`: checks topic relevance for a candidate paper.
- `with_metadata_source_facts`: adds metadata source facts where needed.
